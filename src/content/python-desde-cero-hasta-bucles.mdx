## 1. ¿Qué es Python?

Python es un lenguaje de programación.

Programar significa escribir instrucciones para que el computador haga algo.

Por ejemplo, podemos pedirle que muestre un mensaje:

```python
print("Hola mundo")
```

Resultado:

```text
Hola mundo
```

La instrucción:

```python
print()
```

sirve para mostrar algo en pantalla.

Por ejemplo:

```python
print("Estoy aprendiendo Python")
print(10)
```

Resultado:

```text
Estoy aprendiendo Python
10
```

La idea principal es simple:

```text
Nosotros escribimos instrucciones
        ↓
Python las ejecuta
        ↓
El computador realiza una acción
```

## 2. Variables

Una variable sirve para guardar información.

Podemos imaginarlas como una caja que tiene un nombre.

Por ejemplo:

```python
edad = 20
```

Aquí estamos diciendo:

```text
Variable: edad
Valor: 20
```

Podemos mostrarla:

```python
edad = 20

print(edad)
```

Resultado:

```text
20
```

También podemos guardar texto:

```python
nombre = "Benjamín"

print(nombre)
```

Resultado:

```text
Benjamín
```

Podemos tener varias variables:

```python
nombre = "Benjamín"
edad = 20
carrera = "Ingeniería"

print(nombre)
print(edad)
print(carrera)
```

También podemos combinarlas:

```python
nombre = "Benjamín"
edad = 20

print("Mi nombre es", nombre)
print("Tengo", edad, "años")
```

Resultado:

```text
Mi nombre es Benjamín
Tengo 20 años
```

## 3. Tipos de datos

No toda la información es del mismo tipo.

Python tiene distintos tipos de datos.

### Números enteros: `int`

Son números sin decimales.

```python
edad = 20
cantidad = 5
temperatura = -2
```

### Números decimales: `float`

Son números que contienen decimales.

```python
altura = 1.75
precio = 2990.5
nota = 5.6
```

### Texto: `str`

El texto se escribe entre comillas.

```python
nombre = "Benjamín"
ciudad = "Copiapó"
```

### Booleanos: `bool`

Un booleano solo puede tener dos valores:

```python
True
False
```

Por ejemplo:

```python
mayor_de_edad = True
tiene_auto = False
```

Podemos pensar en ellos como respuestas de:

```text
Sí → True
No → False
```

## 6. Operadores matemáticos importantes

```text

//  división entera
```


```text
8
```


## 8. Un detalle importante de `input()`

`input()` siempre entrega texto.

Por ejemplo:

```python
edad = input("Ingrese su edad: ")
```

Aunque escribamos:

```text
20
```

Python lo guarda como texto.

Sería equivalente a:

```python
edad = "20"
```

Por eso esto genera un problema:

```python
edad = input("Ingrese su edad: ")

print(edad + 1)
```

Python intenta hacer:

```text
"20" + 1
```

y no puede sumar texto con un número.

## 10. Comparaciones

Muchas veces necesitamos que el programa compare valores.

Por ejemplo:

```python
edad = 20
```

Queremos saber:

```text
¿edad es mayor o igual a 18?
```

En Python escribimos:

```python
edad >= 18
```

Esto devuelve:

```text
True
```

porque `20` es mayor que `18`.

Los principales operadores son:

```text
==  igual
!=  distinto
>   mayor que
<   menor que
>=  mayor o igual
<=  menor o igual
```

Ejemplos:

```python
print(5 == 5)
print(10 > 3)
print(2 < 1)
```

Resultado:

```text
True
True
False
```

Importante:

```text
=  sirve para guardar un valor
== sirve para comparar
```

Por ejemplo:

```python
edad = 20
```

guarda `20`.

Pero:

```python
edad == 20
```

pregunta si `edad` vale `20`.

## 11. Condicional `if`

Un `if` permite tomar decisiones.

Por ejemplo:

```text
Si tengo 18 años o más
    puedo entrar
```

En Python:

```python
edad = 20

if edad >= 18:
    print("Puedes entrar")
```

Resultado:

```text
Puedes entrar
```

La estructura es:

```python
if condicion:
    codigo
```

Importante: el código que pertenece al `if` debe tener sangría.

Correcto:

```python
if edad >= 18:
    print("Mayor de edad")
```

Incorrecto:

```python
if edad >= 18:
print("Mayor de edad")
```

## 12. `if` y `else`

¿Qué pasa si la condición no se cumple?

Podemos usar `else`.

```python
edad = 16

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

Resultado:

```text
Menor de edad
```

Podemos leerlo así:

```text
SI edad >= 18
    mostrar "Mayor de edad"
SI NO
    mostrar "Menor de edad"
```

## 13. `elif`

A veces necesitamos más de dos opciones.

Por ejemplo, según una nota:

```python
nota = 5.5

if nota >= 6:
    print("Muy buena nota")
elif nota >= 4:
    print("Aprobado")
else:
    print("Reprobado")
```

Python revisa desde arriba hacia abajo.

Si `nota = 5.5`:

```text
¿nota >= 6?
No

¿nota >= 4?
Sí

→ Aprobado
```

## 23. ¿Qué es un bucle?

Un bucle sirve para repetir instrucciones.

Supongamos que queremos mostrar `"Hola"` cinco veces.

Podríamos hacer:

```python
print("Hola")
print("Hola")
print("Hola")
print("Hola")
print("Hola")
```

Funciona, pero es repetitivo.

Con un bucle podemos hacer:

```python
for i in range(5):
    print("Hola")
```

Resultado:

```text
Hola
Hola
Hola
Hola
Hola
```

También podemos escribir:

```python

```

en vez de:


## 35. Entender `while` paso a paso

Tenemos:

```python
contador = 1

while contador <= 5:
    print(contador)
    contador += 1
```

Primero:

```text
contador = 1
```

Python pregunta:

```text
¿1 <= 5?
```

Sí.

Entonces imprime:

```text
1
```

Después:

```python
contador += 1
```

Ahora:

```text
contador = 2
```

Python vuelve a preguntar:

```text
¿2 <= 5?
```

Y continúa hasta llegar a:

```text
contador = 6
```

Entonces:

```text
¿6 <= 5?
```

No.

El bucle termina.

## 36. Diferencia entre `for` y `while`

Normalmente usamos `for` cuando sabemos cuántas veces queremos repetir algo.

Ejemplo:

```python
for i in range(5):
    print(i)
```

Sabemos que serán cinco repeticiones.

Usamos `while` cuando queremos repetir algo hasta que ocurra alguna condición.

Ejemplo:

```python
password = ""

while password != "python":
    password = input("Ingrese contraseña: ")
```

No sabemos cuántos intentos necesitará la persona.

## 38. Cuidado con los bucles infinitos

Mira este código:

```python
contador = 1

while contador <= 5:
    print(contador)
```

Hay un problema.

`contador` nunca cambia.

Siempre vale:

```text
1
```

Por lo tanto siempre se cumple:

```text
1 <= 5
```

El bucle nunca termina.

La solución es actualizar la variable:

```python
contador = 1

while contador <= 5:
    print(contador)
    contador += 1
```

## 39. `break`

`break` permite salir de un bucle.

Ejemplo:

```python
while True:

    numero = int(input("Ingrese 0 para salir: "))

    if numero == 0:
        break

    print("Ingresaste:", numero)
```

Aquí:

```python
while True:
```

crea un bucle que podría ejecutarse para siempre.

Pero cuando:

```python
numero == 0
```

se ejecuta:

```python
break
```

y el bucle termina.

## 40. `continue`

`continue` permite saltarse una repetición.

Ejemplo:

```python
for numero in range(1, 6):

    if numero == 3:
        continue

    print(numero)
```

Resultado:

```text
1
2
4
5
```

Cuando:

```text
numero = 3
```

Python ejecuta:

```python
continue
```

y pasa directamente a la siguiente vuelta.

## 42. Ejemplo: calcular promedio

Queremos pedir tres notas y calcular su promedio.

```python
suma = 0

for i in range(3):

    nota = float(input("Ingrese una nota: "))

    suma += nota

promedio = suma / 3

print("Promedio:", promedio)
```

Paso a paso:

```text
1. suma comienza en 0
2. pedimos una nota
```

## 49. Resumen

Hasta este punto aprendiste cuatro ideas fundamentales.

### Guardar información

```python
nombre = "Benjamín"
edad = 20
```

### Tomar decisiones

```python
if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

### Guardar varios datos

```python
notas = [5.5, 6.0, 4.8]
```

### Repetir instrucciones

```python
for i in range(5):
    print(i)
```

o:

```python
while condicion:
    # código
```

Podemos resumirlo así:

```text
Variables
    ↓
Guardan información

if / elif / else
    ↓
Permiten tomar decisiones

Listas
    ↓
Guardan varios valores

for / while
    ↓
Permiten repetir instrucciones
```

Con estas herramientas ya puedes comenzar a crear programas pequeños por tu cuenta.

El siguiente paso recomendable sería aprender funciones y practicar ejercicios que mezclen variables, listas, condicionales y bucles.
