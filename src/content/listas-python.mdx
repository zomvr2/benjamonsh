Las **listas** son una de las estructuras más importantes de Python. Sirven para guardar varios valores y trabajar con ellos en orden. En este tutorial vamos desde lo básico (qué es una lista, índices, métodos) hasta un ejemplo práctico de **ordenamiento paso a paso**.

## 1. ¿Qué es una lista?

Una lista guarda **varios valores** dentro de una sola variable. Se escribe con corchetes `[]` y cada elemento va separado por comas.

```python
numeros = [10, 20, 30, 40]
nombres = ["Ana", "Luis", "Pedro"]
mixta = [1, "hola", 3.5, True]
```

También puede estar vacía:

```python
vacia = []
```

## 2. Índices: cómo funcionan las posiciones

Cada elemento tiene un **índice**, su posición. Python empieza a contar desde **0**:

```python
frutas = ["manzana", "pera", "plátano", "uva"]
# índices:      0         1         2        3

print(frutas[0])  # manzana
print(frutas[3])  # uva
```

Si usas un índice que no existe, por ejemplo `frutas[10]`, obtienes un `IndexError`.

> Regla mental: el primer elemento está en la posición 0.

## 3. Índices negativos

Los índices negativos cuentan desde el final:

```python
frutas = ["manzana", "pera", "plátano", "uva"]
# positivos:   0        1         2        3
# negativos:  -4       -3        -2       -1

print(frutas[-1])  # uva (último)
print(frutas[-2])  # plátano
```

## 4. Modificar elementos

Las listas son **mutables**: se pueden cambiar.

```python
numeros = [10, 20, 30]
numeros[1] = 99
print(numeros)  # [10, 99, 30]
```

## 5. Agregar elementos

`append()` agrega al final:

```python
frutas = ["manzana", "pera"]
frutas.append("plátano")
print(frutas)  # ["manzana", "pera", "plátano"]
```

`insert()` agrega en una posición específica:

```python
frutas = ["manzana", "plátano"]
frutas.insert(1, "pera")
print(frutas)  # ["manzana", "pera", "plátano"]
```

## 6. Largo de una lista

```python
frutas = ["manzana", "pera", "plátano"]
print(len(frutas))  # 3
```

## 7. Eliminar elementos

`remove()` elimina por valor (solo la primera aparición):

```python
frutas = ["manzana", "pera", "plátano", "pera"]
frutas.remove("pera")
print(frutas)  # ["manzana", "plátano", "pera"]
```

`pop()` elimina por índice y devuelve el elemento. Sin índice, borra el último:

```python
frutas = ["manzana", "pera", "plátano"]
eliminado = frutas.pop(1)
print(eliminado)  # "pera"
print(frutas)     # ["manzana", "plátano"]
frutas.pop()      # quita "plátano"
```

## 8. Recorrer una lista con `for`

Modo simple:

```python
for fruta in frutas:
    print(fruta)
```

Usando índices:

```python
for i in range(len(frutas)):
    print(i, frutas[i])
```

## 9. Revisar si un elemento está en la lista

```python
frutas = ["manzana", "pera", "plátano"]
print("pera" in frutas)    # True
print("sandía" in frutas)  # False
```

## 10. Slicing: obtener sublistas

La sintaxis es `lista[inicio:fin]`. Incluye `inicio` y excluye `fin`.

```python
numeros = [10, 20, 30, 40, 50]
print(numeros[1:4])  # [20, 30, 40]
print(numeros[:3])   # [10, 20, 30]
print(numeros[2:])   # [30, 40, 50]
```

## 11. Listas dentro de listas

```python
matriz = [
    [1, 2, 3],
    [4, 5, 6]
]
print(matriz[0])     # [1, 2, 3]
print(matriz[0][1])  # 2
```

## 12. Ejemplo práctico: ordenar una lista paso a paso

Este código junta todo lo anterior (listas, `len()`, bucles `for`, comparaciones e intercambio de valores) para ordenar una lista de menor a mayor:

```python
lista = [1, 3, 2, 5]

for i in range(len(lista)):
    for j in range(i + 1, len(lista)):
        if lista[i] > lista[j]:
            aux = lista[i]
            lista[i] = lista[j]
            lista[j] = aux

print(lista)  # [1, 2, 3, 5]
```

### Qué hace cada parte

1. **El primer `for` recorre los índices.** `len(lista)` vale 4, así que `range(4)` genera 0, 1, 2 y 3. `i` es la posición desde donde comparamos.
2. **El segundo `for` compara con los elementos siguientes.** Empieza en `i + 1`, así nunca comparamos un elemento consigo mismo ni hacia atrás. Si `i = 0`, `j` va de 1 a 3; si `i = 2`, solo toma el valor 3.
3. **La comparación.** Si el valor en `i` es mayor que el valor en `j`, están al revés para un orden ascendente, así que se intercambian.
4. **El intercambio (swap).** Guardamos `lista[i]` en `aux`, ponemos `lista[j]` en `lista[i]` y luego lo guardado en `lista[j]`. Así no se pierde ningún valor.

### Mini recorrido

Partimos con `[1, 3, 2, 5]`:

- Con `i = 0` el valor es 1. Se compara con 3, 2 y 5; nunca es mayor, así que nada cambia.
- Con `i = 1` el valor es 3. Contra 2 sí es mayor: se intercambian y la lista queda `[1, 2, 3, 5]`. Contra 5, nada.
- Con `i = 2` el valor es 3. Contra 5, nada.
- Con `i = 3` ya estamos en el último valor.

Resultado: `[1, 2, 3, 5]`. Es un algoritmo simple, ideal para entender cómo recorrer con índices, comparar elementos e intercambiar valores.

## 13. Resumen de funciones y métodos

| Método | Qué hace | Ejemplo |
|---|---|---|
| `len(lista)` | Número de elementos | `len([5, 10, 15])` da `3` |
| `append(x)` | Agrega `x` al final | `nombres.append("Pedro")` |
| `insert(i, x)` | Inserta `x` en la posición `i` | `[10, 30].insert(1, 20)` |
| `remove(x)` | Elimina la primera aparición de `x` | `[1, 2, 2, 3]` queda `[1, 2, 3]` |
| `pop(i)` / `pop()` | Elimina y devuelve un elemento | `frutas.pop(1)` da `"pera"` |
| `clear()` | Deja la lista vacía | `numeros.clear()` |
| `index(x)` | Índice de la primera aparición | `frutas.index("pera")` da `1` |
| `count(x)` | Cuántas veces aparece `x` | `[1, 2, 2, 3, 2].count(2)` da `3` |
| `sort()` | Ordena la lista | `[5, 1, 4, 2]` queda `[1, 2, 4, 5]` |
| `reverse()` | Invierte el orden | `[1, 2, 3]` queda `[3, 2, 1]` |
| `copy()` | Crea una copia independiente | `copia = original.copy()` |
| `list(iterable)` | Convierte algo en lista | `list(range(5))` |
| `min()`, `max()`, `sum()` | Mínimo, máximo y suma | `sum([5, 10, 3])` da `18` |

Con esto ya puedes trabajar con listas en casi cualquier programa. Lo demás sale practicando ;)
